여의도 착석바·토킹바 예약 방법 안내

여의도 라운지의 예약은 카카오톡 채널 또는 전화 두 가지 방식으로 24시간 가능합니다. 처음 예약하시는 분도 부담 없이 진행하실 수 있도록 단계별로 정리했습니다.

예약이 필요한 경우

  • 금요일 저녁·주말 자리가 빨리 마감되어 사전 예약 권장
  • 6인 이상 단체 룸 배치 조율을 위해 사전 예약 권장
  • 특정 시간대 지정 원하는 시간이 정해진 경우
  • 특별 요청 분위기·룸 조건 조율이 필요한 경우
  • 평일 일반 방문은 예약 없이도 즉시 입장 자주 가능

당일 예약 가능 여부

평일은 당일 예약도 자주 가능합니다. 출발 30분 전 정도에 카카오톡으로 한 번만 알려주시면 룸이 준비된 상태로 입장하실 수 있습니다. 주말·금요일은 자리 가용도가 빠르게 변하므로 더 일찍 문의하시면 좋습니다.

전화 문의 시 확인할 내용

  • 방문 인원 정확한 인원 (변동 가능성도 함께)
  • 방문 시간 도착 예상 시각
  • 이용 시간 머무를 예상 시간 (대략)
  • 분위기 선호 조용·차분 또는 편안·활발
  • 예약자 성명·연락처 본인 또는 단체 대표

방문 시간과 인원 전달 방법

카카오톡 채널이 가장 편합니다. "오늘 21시 4명, 토킹바 룸으로 부탁드립니다" 정도로 메시지 한 줄만 보내주시면 응답이 오고 룸 안내가 진행됩니다. 인원이 늦게 합류하실 예정이면 그것도 같이 알려주세요.

단체 예약 시 확인사항

6인 이상 단체는 룸 배치 조율이 필요하므로 가능하시면 하루 이상 전에 문의해 주세요. 8인 초과 시 룸 2개 사용 또는 인접 룸을 함께 쓰는 방식으로 안내됩니다. 자세한 안내는 단체 모임 예약 안내에서 확인하실 수 있습니다.

예약 변경 또는 취소 전 확인사항

  • 예약금 없음 — 변경·취소 부담 없음
  • 가급적 방문 2시간 전 까지 변경·취소 연락 권장
  • 인원 변경 시 룸 크기 조정 필요할 수 있음
  • 무단 노쇼가 반복되면 향후 예약 제한 가능

예약·문의는 24시간 가능합니다
